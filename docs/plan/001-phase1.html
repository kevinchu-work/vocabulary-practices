Plan 001 — Phase 1 Implementation

Date: 2026-07-12  ·  Implements docs/decision/001-stack.html  ·  Status: not started (docs only)

Goal

A working single-user loop: look up a word on macOS → save it to the server → practise spelling it in the browser. Definitions and examples come from Merriam-Webster's Learner's Dictionary; the server is a Cloudflare Worker backed by Workers KV.

Architecture

 macOS menu-bar app ──HTTPS + bearer key──▶  Cloudflare Worker  ──server-side MW key──▶  MW Learner's API
   (hotkey → capture                              │   │
    selected text)                                │   └──▶  Workers KV
                                                  │           • def:<word>   cached lookups (30-day TTL)
                                                  │           • word:<word>  saved vocabulary
                                                  └──▶  serves the Practice web page at  /

Components

#ComponentTech
1API + static page hostCloudflare Worker (TypeScript), Wrangler 4
2StorageWorkers KV (one namespace, key prefixes def: / word:)
3Practice web pageVanilla HTML/CSS/JS, served at /
4macOS front-endSwiftPM executable, SwiftUI MenuBarExtra, KeyboardShortcuts lib, packaged as a .app

API surface

Method & pathBehaviour
GET /lookup?word=Check def:<word> in KV; on miss call MW, normalise, cache (30-day TTL), return {word, definitions[], examples[], pronunciation}.
POST /wordsBody {word}. Reuse cached lookup, store word:<word>.
GET /wordsList saved words via KV prefix scan on word:.
DELETE /words/:wordRemove a saved word.
POST /practice/resultBody {word, correct}. Increment timesPracticed, record lastCorrect.
GET /Serve the practice web page.

All API routes require an Authorization: Bearer <token> header (single shared secret, stored as a Worker secret).

Data model (KV)

def:<word>   → { word, definitions[], examples[], pronunciation }        // lookup cache, TTL 30d
word:<word>  → { word, definition, examples[], savedAt,                  // saved vocabulary
                 timesPracticed, lastCorrect }

No separate index is needed — saved words are enumerated with a word: prefix list.

Build order & verification

Backend first (testable with curl alone); native UI last.

Step 1 — Worker skeleton + KV + auth + /lookup

  • Scaffold Worker, bind a KV namespace, add bearer-token middleware.
  • Implement MW Learner's fetch + normaliser (extract definitions and vis example sentences) + KV caching.
  • Verify: curl returns normalised JSON for a word; a second call is served from cache (log/timing confirms cache hit).

Step 2 — Save / list / delete / practice-result

  • Implement POST/GET/DELETE /words and POST /practice/result.
  • Verify: curl round-trip saves and lists a word; wrangler kv key list shows the word: entry; practice-result mutates the counters.

Step 3 — Practice web page at /

  • Vanilla page: pull GET /words, show a word's definition/example with the word hidden, accept typed input, score, and POST the result.
  • Verify: open in a browser, practise a few saved words, confirm scores/counters update server-side.

Step 4 — macOS menu-bar app

  • SwiftPM executable with MenuBarExtra; register a global hotkey via KeyboardShortcuts.
  • On hotkey: simulate ⌘C, read NSPasteboard, call GET /lookup, render definition in a popover with a Save button → POST /words.
  • Package as a .app bundle (LSUIElement/accessory policy) via a small build script.
  • Verify: select a word in TextEdit, press the hotkey, see the definition, click Save, and confirm it appears in GET /words and on the practice page.

Manual steps you own

  • Cloudflare: run wrangler login (interactive) once.
  • Merriam-Webster: register at dictionaryapi.com and obtain a free Learner's Dictionary key; provide it so it can be set as a Worker secret (wrangler secret put MW_KEY).
  • Shared API token: pick a secret string for the bearer token (set via wrangler secret put API_TOKEN).
  • macOS Accessibility: grant the menu-bar app Accessibility access in System Settings when prompted (needed to read the selected text).

Risks & mitigations

RiskMitigation
MW free quota (1,000/day)KV cache on def: — repeated words never re-hit MW.
MW markup tokens in responsesDedicated normaliser; unit-test against a couple of sample payloads.
Accessibility permission resets on rebuildStable bundle id + build path; re-grant is a one-click step. Document it.
Reading selection via ⌘C clobbers clipboardSave & restore previous clipboard contents around the copy.

Out of scope for Phase 1

  • Multi-user accounts / real auth (single static token only).
  • Audio pronunciation playback (MW provides it — a Phase-2 add).
  • Spaced-repetition scheduling / analytics.
  • Code signing, notarisation, and distribution of the Mac app (dev build only).
  • iOS / mobile clients.
